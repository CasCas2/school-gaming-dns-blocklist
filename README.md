# MEGA School Gaming Blocklist

A DNS blocklist designed to block **browser games, .io games, and unblocked game sites** commonly used in schools.

This list is compatible with:

- AdGuard Home
- Pi-hole
- pfSense / pfBlockerNG
- Technitium DNS
- NextDNS
- any DNS system supporting **hosts format**

---

# What this list blocks

The blocklist focuses on the most common **school gaming and distraction sites**:

### Browser game portals
- CrazyGames
- Poki
- Friv
- CoolMathGames
- SilverGames
- ArmorGames
- Kongregate
- Miniclip
- GamePix
- GameFlare

### .io games
- bloxd.io
- slither.io
- agar.io
- krunker.io
- moomoo.io
- smashkarts.io
- starblast.io
- skribbl.io

### Unblocked game sites
- unblockedgames66
- unblockedgames76
- unblockedgames911
- classroom6x
- classroom10x
- classroom30x

### Soundboards / distractions
- myinstants.com
- soundboardguy.com
- 101soundboards.com

### Cloud gaming
- now.gg
- cloudgames.gg

### Browser game mirrors
- github.io mirrors
- classroom mirrors
- slope / run3 mirrors
